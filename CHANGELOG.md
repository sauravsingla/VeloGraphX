# Changelog

## 0.2.0 - 2026-08-26

- Added hybrid dynamic graph baseline with versioned update batches and compaction.
- Added incremental triangle counting, connected components, BFS, SSSP and PageRank state.
- Added adaptive intersection policy, frontier and execution planner/explain API.
- Added thread pool, aligned allocation, NUMA and memory-budget abstractions.
- Added native binary graph I/O and optional pybind11 bindings.
- Expanded dynamic tests, benchmarks, research documents, limitations and paper scaffold.
