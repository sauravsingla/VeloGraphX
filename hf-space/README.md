# VeloGraphX — Repair vs Recompute

Static, browser-only companion to the VeloGraphX benchmark dataset. It visualizes the **retained publication selector regimes** copied directly from `paper/data/current-selector-regimes.csv` in the canonical GitHub repository.

The Space does not run new benchmarks or synthesize measurements. Every displayed value is versioned evidence from the source repository.

- Dataset: https://huggingface.co/datasets/sauravsingla08/velographx-benchmarks
- Source: https://github.com/sauravsingla/VeloGraphX
- Documentation: https://sauravsingla.github.io/VeloGraphX/
- Frozen archive: https://doi.org/10.5281/zenodo.22842292
